Быстрый старт

Минимальный HTML-документ: doctype, язык, кодировка и viewport.

<!DOCTYPE html> 
<html lang="ru">
Зачем lang и charset?

lang помогает скринридерам, а charset спасает русские буквы от кракозябр.

Зачем нужен meta viewport?

Масштаб на мобильных без «десктопного» уменьшения

Почему <title> важен?

Вкладка, закладки, сниппет в поиске

Селекторы

CSS находит элементы по тегу, классу, id и состоянию.

.card:hover { color: red; }
Что сильнее: класс или id?

id сильнее класса; при равенстве побеждает последнее правило.

Что делает * ?

Универсальный селектор, где полезен и где опасно переборщить

Блоковая Модель

Элемент = контент + padding + border + margin.

* { box-sizing: border-box; }
Зачем box-sizing: border-box?

Чтобы ширина уже включала отступы и рамку — так проще считать.

Что такое схлопывание margin?

Вертикальные отступы соседей могут схлопнуться в один

Столбец или ряд - Flexbox

Раскладывает элементы в одну линию: в ряд или в столбец.

.row { display: flex; gap: 16px; }
Чем justify-content отличается от align-items?

justify работает по главной оси, align — по поперечной.

Что делает flex-wrap?

Перенос на новую строку, когда не хватает места

Что такое flex: 1?

Краткая запись grow/shrink/basis и делёж свободного места

Grid

Сетка из строк и столбцов для двумерных макетов.

repeat(auto-fit, minmax(200px, 1fr))
Что делает auto-fit?

Сам подбирает количество колонок под доступную ширину.

Чем fr отличается от % ?

Доля свободного пространства grid vs процент от контейнера.

Адаптив

Сначала стили для телефона, потом расширяем через @media.

@media (min-width: 768px) { ... }
Почему mobile-first?

Так проще: на узком экране не приходится переопределять лишнее.

Что делает prefers-reduced-motion?

Уважение к настройке пользователя уменьшить анимации.

Почему лучше ставить брейкпоинты по контенту?

Дизайн ломается не «по устройству», а по ширине/контенту

Формы

У каждого поля нужен label, а placeholder — только подсказка.

<label for="email">Почта</label>
Почему нельзя заменить label на placeholder?

Placeholder исчезает при вводе и плохо читается скринридерами.

Зачем type="email"/tel/number?

Клавиатура, встроенная валидация, семантика

Доступность

Семантика, контраст и видимый фокус делают сайт удобным для всех.

<img src="coffee.jpg" alt="Чашка кофе">
Что писать в alt?

Краткое описание картинки; декоративную — alt="".

Зачем видимый фокус?

Клавиатурная навигация; без него непонятно, где ты находишься.

Цвета и переменные

Переменные CSS задают значения один раз и переиспользуют через var(). 

Объявление переменной в :root и использование её в body или .button
Зачем переменные, если можно просто писать цвет?

Меняешь в одном месте — обновляется везде; удобно для темы

Чем hex отличается от rgb/hsl?

Разные способы записи; где удобнее прозрачность/настройка оттенка.

Единицы

px фиксирован, rem привязан к корневому шрифту, % — к родителю.

Пример с font-size: 1rem, padding: 1.5rem, width: 100%
Когда брать rem, а когда px?

rem — для текста и отступов, px — для тонких рамок/деталей

Что такое vh/vw?

Проценты от окна просмотра и где они полезны/коварны.

Позиционирование

position меняет, как элемент размещается: в потоке, относительно себя или окна. 

position: sticky; top: 0; или пара relative + absolute
Почему absolute иногда «улетает»?

Он позиционируется от ближайшего родителя с position, не static

Чем sticky отличается от fixed?

Прилипает внутри контейнера vs всегда относительно окна

Текст и шрифты

Читаемость зависит от шрифта, размера, межстрочного интервала и длины строки. 

line-height: 1.6; и ограничение ширины текста через max-width в ch
Почему line-height лучше писать без px?

Без единицы это множитель — он масштабируется вместе со шрифтом

Переходы

transition плавно меняет свойство, а transform хорошо анимируется. 

transition для кнопки и изменение transform на :hover
Какие свойства анимировать безопаснее?

opacity и transform — они обычно не вызывают тяжёлый перерасчёт layout

Картинки

Картинка должна вписываться в контейнер и иметь понятный alt.

img { max-width: 100%; height: auto; display: block; }
Зачем max-width: 100%?

Чтобы картинка не вылезала за пределы блока на узком экране

Когда alt должен быть пустым?

Декоративное изображение, которое не несёт смысла

Display

Чем отличаются блочные, строчные и inline-block элементы

Сравни block, inline, inline-block, none
Почему у inline не работают width и height?

Строчный элемент занимает ширину содержимого и не создаёт блочную коробку
